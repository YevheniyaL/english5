1Что значит? U1 ✏️

На столе книга.There is a book on the table. В классе 7 мальчиков.There are seven boys.

Порядок слов:

There is / are+что?+где?

On the table is a book.

2is или are? U1 📖 стр. 9

одинThere is = There's a teacher.
многоThere are seven boys.

Считаем — число: There's one computer.

Не считаем: a / an — один · some — несколько · a lot of — много

There are some posters. · There are a lot of books.

3Один, много или нет? U1 U3 📖 стр. 9, 29

There's a…
один
There's a park.
There's an interesting shop.
There are some…
много
There are two restaurants.
There are some museums.
isn't a / aren't any
нет (Unit 3)
There isn't a park.
There aren't any shops.
💡 some — в утверждении · any — в отрицании и вопросе. 📖 стр. 29, 31   There aren't some shops.

4Вопрос и ответ U3 📖 стр. 31

Is there a cinema?Yes, there is. / No, there isn't.
Are there any cafés?Yes, there are. / No, there aren't.

How many shops are there? — Two thousand.

5Где или у кого? ✏️

Где есть? В комнате кошка.There is a cat in the room. У кого есть? У меня кошка.I have got a cat.

где → there is / are · у кого → have got / has got

6Не ошибись! ✏️

  • There are a book. → There is a book.
  • There is two cats. → There are two cats.
  • There are some poster. → posters
  • Is there any cafés? → Are there…
  • Yes, there's. → Yes, there is.
  • There is a cat at me. → I have got a cat.
