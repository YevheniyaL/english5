there is / there are

Сейчас в Unit 1 достаточно разделов 1–3. Разделы 4–5 понадобятся в Unit 3.

1Что значит there is U1 ✏️

Так говорят, что где-то есть или находится что-то:

На столе книга.There is a book on the table. В классе семь мальчиков.There are seven boys in the class. В нашем городе есть парк.There is a park in our town.

Порядок слов другой, чем в русском! По-русски начинаем с места («На столе…»), по-английски — с there:

There is / There are+что?+где?

On the table is a book. → There is a book on the table. Слово there здесь не переводится — это просто «начало» предложения.

2is или are? U1 📖 стр. 9

полная формакороткаяпример
один предметthere isthere'sThere's a teacher.
многоthere are—There are seven boys.

Как в теме be ✏️: смотрим, один или много того, о чём говорим — хвостик -s, числа (two, seven), some, a lot of, children, people → are.

✏️ «There are» обычно не сокращают — говорят полностью.

3a, some, a lot of или число? U1 📖 стр. 9

Если считаем — ставим число: There's one computer. There are seven boys and there are nine girls.

Если не считаем:

  • a / an — один: There's a teacher. · There's an interesting shop. 📖 стр. 29
  • some — несколько: There are some posters.
  • a lot of — много: There are a lot of books.

✏️ После some и a lot of — всегда are и слово с -s: There are some posters.

4Отрицание: some или any? U3 📖 стр. 29

один — утверждение
There's a park.
There's an interesting shop.
много — утверждение
There are two restaurants.
There are some museums.
нет — отрицание
There isn't a park.
There aren't any shops.
💡 Правило из учебника: some — в утверждении, any — в отрицании (и в вопросе). 📖 стр. 29, 31
There aren't some shops. → There aren't any shops. ✏️

5Вопрос и краткий ответ U3 📖 стр. 31

is / are — в начало, there — сразу после:

ВопросДаНет
Is there a cinema?Yes, there is.No, there isn't.
Are there any cafés?Yes, there are.No, there aren't.

Сколько? How many shops are there? — Two thousand. 📖

✏️ После How many — всегда are there (много). В «да» не сокращаем: Yes, there's. → Yes, there is.

6there is или have got? ✏️

Оба переводятся «есть», но спрашивают разное:

Где есть? — В комнате есть кошка.There is a cat in the room. У кого есть? — У меня есть кошка.I have got a cat. В нашем городе есть парк.There is a park in our town. У Aliya есть брат.Aliya has got a brother.

Подробно про «у меня есть» — have got / has got →

7Частые ошибки ✏️

  • There are a book on the table.There is a book on the table.
  • There is two cats.There are two cats.
  • On the table is a book.There is a book on the table.
  • There are some poster.There are some posters.
  • There aren't some shops.There aren't any shops.
  • Is there any cafés?Are there any cafés?
  • Yes, there's.Yes, there is.
  • There is a cat at me. (у меня есть кошка) I have got a cat.
